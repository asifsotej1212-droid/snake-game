# 🐍 ৬ জনের সাপের খেলা

ব্রাউজারে খেলার মতো একটি সাপের খেলা। সাপের মাথায় ৬ জনের মুখ, ফল খেলে সাপ বড় হয় আর গতি ধীরে ধীরে বাড়ে। সাউন্ড ও ব্যাকগ্রাউন্ড মিউজিক আছে।

## খেলার নিয়ম
- তীর চিহ্ন / WASD দিয়ে চালাও
- Space = বিরতি
- মোবাইলে স্ক্রিনের বাটন বা সোয়াইপ

## চালানোর উপায়
`index.html` ফাইলটি ব্রাউজারে খুললেই হবে। কোনো ইনস্টলেশন লাগে না।
